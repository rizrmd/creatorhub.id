# CreatorHub.id

Creator Marketplace — KOL / Content Creator platform for Indonesia.

A modern dashboard for discovering, filtering, and connecting with Indonesian content creators (KOLs) across Instagram, TikTok, and YouTube.

## Features

- Creator marketplace with search & filters
- Category, location, platform, follower count, and engagement filters
- Interactive map view
- Creator detail modals with campaign pricing
- Responsive design

## Tech Stack

- Vite
- Vanilla JS + HTML + CSS
- Leaflet.js for maps

## Getting Started

```bash
cd docs/reference
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Project Structure

- `docs/reference/` — Main application source
- `docs/reference/dist/` — Production build output
